# 샘플 영상

2주차 파이프라인 검증(컷 분할 + 얼굴 임베딩 임계값)에 쓸 영상을 모으는 폴더.
**영상·이미지 파일은 git에 올리지 않는다** (`.gitignore` 처리). 이 README와 목록만 커밋한다.

## 기준

- **권리**: 직접 만들었거나 사용 허락을 받은 영상만. 출처를 아래 목록에 적는다.
- **개수**: 3~5개 (같은 시리즈의 회차 2개 이상이 들어 있으면 좋음 — 회차 간 비교 테스트용)
- **화풍**: 실사 1~2개 + 애니·만화체 1~2개 (애니 얼굴 인식 정확도가 가장 큰 리스크)
- **길이**: 1~10분
- **내용**: 같은 캐릭터가 여러 컷에 반복 등장. 가능하면 *일부러 얼굴이 달라진 컷*이 섞인 영상 (정답 라벨링용)
- **레퍼런스**: 각 시리즈의 캐릭터 레퍼런스 이미지(정면 필수, 측면 있으면 좋음)를 함께 둔다

## 폴더 구조

```
samples/
  <시리즈-이름>/
    refs/          캐릭터·장소 레퍼런스 이미지
    ep01.mp4
    ep02.mp4
    ep01.labels.csv  (2주차) 회차별 정답 라벨: time,character,label (label = ok/ng)
```
